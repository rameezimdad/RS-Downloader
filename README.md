# RS Downloader Releases

Windows installers for **RS Downloader**, a desktop app by Rameez Scripts that saves public videos and MP3 audio from a pasted link.

This repository holds release files only. Installed apps check it for new versions and update themselves.

## Install

1. Open the latest release on the right.
2. Download `RS-Downloader-Setup-<version>.exe` and run it.
3. Windows may show "Unknown publisher". Click More info, then Run anyway.

## Updates

The app checks for a new version at start and every hour, downloads it in the background, and installs it on restart. The Update button in the sidebar does the same on demand.
