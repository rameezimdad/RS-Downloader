# RS Downloader Releases

Windows installers for **RS Downloader**, a desktop app by Rameez Scripts that saves public videos, MP3 audio, pictures and files from a pasted link.

This repository holds release files only. Installed apps check it for new versions and update themselves.

## Install the app

1. Download **[RS-Downloader-Setup (latest)](https://github.com/rameezimdad/RS-Downloader-Releases/releases/latest)** and run it.
2. Windows may show "Unknown publisher". Click More info, then Run anyway.
3. Everything it needs is inside the installer. Open it and start downloading.

## Browser extension (Chrome, Edge, Brave, Opera, Vivaldi)

Adds a **Download this video** button with a quality list on every video, a right-click menu, and catches browser downloads.

1. Download **[RS-Downloader-Extension.zip](https://github.com/rameezimdad/RS-Downloader-Releases/releases/latest/download/RS-Downloader-Extension.zip)** and unzip it.
2. Open `chrome://extensions` (Edge: `edge://extensions`) and turn on **Developer mode**.
3. Click **Load unpacked** and pick the `RS-Downloader-Extension` folder.

The app must be running; the extension talks only to it on this PC. RS Downloader can also do these steps for you: Options > Browser > Install.

## Updates

The app checks for a new version at start and every hour, downloads it in the background, and installs it on restart. The Update button does the same on demand.
